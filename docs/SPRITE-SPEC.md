# SPRITE-SPEC — falinks 像素办公室

> 画风:暖色温馨俯视 2.5D cozy 像素风(Stardew Valley / 宝可梦室内调性)。
> 参考图:`docs/office-ref/style-ref.png`。
> 核心原则:**共用骨架**——所有小人同一 16×24 坐姿骨架,差异只靠状态色 + 1–2px 微动;
> 切换状态/角色不改形体,只换调色与浮标。

视角:**俯视微透视**(top-down,带轻微正面倾斜),不是等距 iso。
家具正面可见、地面平铺;小人正面坐姿,全身基本不被遮挡。

## 2. 状态系统(5 态:idle / busy / waiting / done / offline)

⚠️ 暖色房间里几乎全是棕/米/暖绿,**状态绝不能只靠"小人身上的色相"**——会被房间吞掉。

两级冗余,**色 + 形 + 面积**三保险,静帧截图也能分清:

**一级(主通道)= 脚下地台 tile 发光**。小人座椅所在的那块俯视方格地砖整体染状态色
(`cozy` 俯视下小人脚边地面可见、面积大,是最强的辨识通道)。tile 用**与房间装饰解耦、
暖调里能跳出来的高饱和点缀色**,带轻微外发光/呼吸。
**二级(冗余)= 头顶形状浮标**(色弱/缩略图也能分),带 1px 深色描边底。

| 状态 | 状态色 | 脚下 tile | 头顶浮标 | 小人/屏幕/台灯氛围 |
|---|---|---|---|---|
| **idle** | 冷灰蓝 `#8893A8` | 不发光(本色地砖) | 无 | 肩 ±1px 慢呼吸、屏暗、台灯微亮 |
| **busy(typing)** | 绿 `#5FB84A` | 绿色脉冲发光 | 实心圆 | 双手 ±1px 交替敲、头微点(~4fps)、屏滚动、台灯亮 |
| **waiting** | 琥珀 `#F2A33C` | 琥珀呼吸发光 | "…" 三点呼吸 | 身体静止、屏显等待点 |
| **done** | 青 `#2FA4C8` | 青光闪 1 次后常亮 1.5s | "✓" 弹出 | 头轻抬一下、屏闪青光后稳定 |
| **offline** | 暗灰 `#5A5A60` | tile 熄灭/压暗 | "!" 或空心 | 小人降 50% 透明、闭眼(横 1px)、屏黑、台灯灭 |

- 一级靠脚下 tile(大面积色)→ 远看/缩略图一眼定位;二级靠头顶形状 → 近看精确区分。
- busy 绿 / done 青 / waiting 琥珀 三者色相拉开,且都在暖底上做高饱和点缀 → 不会糊。
- 微动只负责"活着"的氛围,**不单独承担状态语义**(防止静帧截图认不出)。
- 多工位同屏时,脚下 tile 发光让"谁在忙/谁在等"一扫即知,无需逐个看头顶。

## 3. 小人规格(16×24,正面坐姿)

```
y0–6   头(含发际)  6×6 居中
y6–8   脖子        2px
y8–16  躯干/衬衫    8×8
y16    桌沿横切贯穿(手搭桌面)
y16–24 下半身/椅子(部分被桌子遮挡)
```
- 眼睛:单像素 ×2,平视;offline 时换成横 1px(闭眼)。
- 手:2×2,搭在桌沿;busy 时左右手 ±1px 交替。
- 头顶上方预留 4–6px 空间给状态浮标。
- 角色区分只换:发色 / 衬衫色(中低饱和,别破坏暖调) —— 骨架不动。

## 4. 工位规格(桌 + 电脑)

- **桌**:木面 `#9C6B3E` 顶 + `#C08B54` 1px 高光,木体 `#7A4F2A`,腿 `#5C3A20`;桌宽约 28–32px。
- **显示器**:边框 `#5C3A20`/`#1E2A33`,屏底 `#1E2A33`,代码行 `#5FB0C8`;busy 滚动、done 闪青、offline 全黑。
- **键盘**:深木 `#7A4F2A` 底 + 按键 1px 高光,busy 时按键随机点亮。
- **台灯**:陶土/木杆 + 暖光晕 `#F2C879`(径向),作为状态氛围副通道(idle 微亮 / 工作亮 / offline 灭)。
- **桌面小物**:咖啡杯、小盆栽、便签 —— 点缀,固定不动。

## 6. 走查红线(防跑偏)

1. 不准出现高饱和荧光/冷调大色块——破坏暖 cozy 调。
2. 状态必须**脚下 tile 发光为主、头顶形状浮标为辅**的两级冗余,不准只靠身体色或仅靠动画。
3. 5 态在**静帧截图**下也必须可区分(浮标色+形状保证)。
4. 所有小人共用同一 16×24 骨架,角色差异只在发色/衫色。
5. 装饰可丰富,但**不能挤占小人头顶浮标区**与显示器可读性。
